# المصادر الرسمية المصرية (بديل مصادر السوق الصينية)

> تاريخ الوصول والتحقق: 2026-11-26. مرجع تشغيلي فقط، مش استشارة قانونية أو بنكية. كل حكم لازم يتأكد مع الجهة المختصة والبنك قبل الاعتماد عليه.
> علامات: [مُتحقق] = صفحة رسمية انفتحت واتقرأت فعلاً في التاريخ ده؛ [غير متحقق] = من مؤشر بحث أو مصدر طرف ثالث، لازم مراجعة يدوية.

## 1) نافذة / ACI — التسجيل المسبق للشحنات (جانب الاستيراد)

| العنصر | القيمة |
|---|---|
| الجهة والرابط | مصلحة الجمارك المصرية — https://customs.gov.eg/Services/ACI [مُتحقق] |
| السند القانوني | المادة 39 من قانون الجمارك 207/2020 + قرارات وزير المالية 38 و328 و430 و490 لسنة 2021 [مُتحقق] |
| التطبيق | إلزامي على الشحنات البحرية الواردة من 1/10/2021؛ بيانات الفاتورة التجارية وبوليصة الشحن قبل الشحن بـ 48 ساعة على الأقل [مُتحقق] |
| رقم ACID | 19 رقماً، لكل شحنة، صالح 6 شهور، لا يُستخرج بعد مغادرة الشحنة؛ يظهر على الفاتورة وبوليصة الشحن والبيان [مصدره PDF على nafeza.gov.eg — غير متحقق مباشرة: الرابط رجع 429] |
| الوكيل | المُخلّص يحتاج توكيل رسمي أو تفويض إلكتروني عبر نافذة بتوقيع إلكتروني؛ المصدر الأجنبي يحتاج حساب CargoX موثّق (مزوّد خاص مش جهة رقابية) [غير متحقق] |
| التواصل | 15460 / aci.support@customs.gov.eg [مُتحقق] |

**تنبيه جوهري:** ACI نظام خاص بالبضائع **الداخلة** مصر، مش بالصادرات المصرية الخارجة. متطلب ما بعد الوصول للدولة المقصودة هو Fasah (السعودية) / IPAFFS (بريطانيا) / TRACES-CHED (الاتحاد الأوروبي) / تصريح MOCCAE (الإمارات). بلاش تطلب ACID لشحنة صادرة من مصر.

## 2) GOEIC — الهيئة العامة للرقابة على الصادرات والواردات

| العنصر | القيمة |
|---|---|
| سجل المُصدّرين | https://www.goeic.gov.eg/en/electronicServices/12 [مُتحقق] — «Export is permitted only for those whose name is listed in the exporters' register» (المادة 39 من لائحة 770/2005؛ قانون 118/1975). قائمة المستندات على الصفحة ما ظهرتش في الاستخراج، راجعها مباشرة. التواصل 19591. |
| اللائحة | قرار 770/2005، الفصل الثالث مواد 52–59 (سجلات A/B، بطاقة تجارية، شهادة مزاولة التصدير، إقرار بعدم الإدانة، التجديد): https://www.goeic.gov.eg/upload/online/2024/03/documents/files/en/1198.pdf [مُتحقق كرابط] |
| شهادات المنشأ | https://www.goeic.gov.eg/en/services-and-activities/Exports-and-origin [مُتحقق] — GOEIC بتُصدر شهادات المنشأ التفضيلية وغير التفضيلية وتتحقق من صحتها بناءً على طلب جمارك الدول المستوردة (قرار 597/2002). |
| المصدر المعتمد | https://www.goeic.gov.eg/ar/services-and-activities/authorized-source [مُتحقق كرابط] — كود المصدر المعتمد على الفاتورة بدل EUR.1/EUR-Med في الاتفاقيات المعمول بها. |
| قواعد مُقيّدة للدخول | قرار 43/2016 المُعدَّل بالقرار 195/2022 (سجل المصانع/الشركات المؤهلة) تُنشر قوائمه شهرياً بالوقائع المصرية وعلى موقع GOEIC؛ مفيش API عام مُؤكد [غير متحقق]. |
| تناقض مُعلن | مدة التجديد 3 سنين في قانون 118/1975 مقابل 5 سنين في لائحة 770/2005 — راجع GOEIC قبل ما تكتب رقم. |

## 5) حدود ما هو متاح علناً
- أغلب تعاميم CBE نصوص PDF مش متاحة عبر الفهرس؛ الترجمات الإنجليزية للكتاب 8 طرف ثالث.
- Nafeza `/en/aci/validate` رجع HTTP 429 وقت الفحص؛ مفيش API عام مُؤكد.
- مفيش مستند إنجليزي واحد مُوحّد بقائمة مستندات ACI — القائمة مجمّعة من customs.gov.eg + ملفات PDF على nafeza.
- «ECTN» مش المصطلح الرسمي؛ المصطلح ACID / ACI Shipment ID.
- قوائم GOEIC المُقيّدة مُنشورة شهرياً بس، مفيش قائمة قابلة للقراءة آلياً.
